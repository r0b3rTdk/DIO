# Projetos Completos

Diferente das outras pastas focadas em tópicos isolados e estudos teóricos ou pequenos exercícios, esta pasta é destinada a projetos maiores que unem vários conceitos.

## O que você encontrará aqui:

1. **Aplicações Front+Back**: Projetos que juntam lógica de backend em Python com interfaces ou APIs.
2. **Desenvolvimento de Apps (Kivy)**: Estudos voltados para a criação de aplicativos desktop/mobile usando frameworks como o Kivy.
