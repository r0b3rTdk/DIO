# Fundamentos do Python

Nesta pasta, você encontrará exercícios focados na base da linguagem Python. 

## Tópicos Abordados:

1. **Entrada e Saída (`input` e `print`)**: Como interagir com o usuário, recebendo dados pelo teclado e exibindo resultados na tela.
2. **Operações Matemáticas**: Adição, subtração, multiplicação, divisão, divisão inteira, módulo (resto da divisão) e potenciação.
3. **Manipulação de Strings**: 
   - Fatiamento (slicing) de textos.
   - Máscaras de formatação (f-strings, `.format()`).
   - Métodos nativos para checagem e alteração de strings (ex: `.isalpha()`, `.isnumeric()`, `.upper()`, `.lower()`).

Esses conceitos formam a fundação para qualquer programa mais complexo que você for construir!
