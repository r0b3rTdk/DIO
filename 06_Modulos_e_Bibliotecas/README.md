# Módulos e Bibliotecas

Aqui você encontra exercícios focados na expansão das funcionalidades nativas do Python através da importação de pacotes.

## Tópicos Abordados:

1. **Importação Básica (`import`)**: Como usar códigos prontos de outras pessoas ou do próprio Python (como `math`, `random`, `datetime`).
2. **Criação de Módulos**: Como criar os seus próprios arquivos `.py` com funções e importá-los em outros scripts, mantendo seus projetos organizados.
3. **Bibliotecas Externas (ex: `pandas`)**: Estudos usando pacotes instalados externamente (via `pip`), essenciais para tarefas avançadas como Análise de Dados e Data Science.
