# Laços de Repetição (Loops)

Nesta pasta, você aprenderá a repetir blocos de código sem precisar reescrevê-los, economizando tempo e recursos.

## Tópicos Abordados:

1. **`for`**: Utilizado quando você sabe a quantidade de vezes que deseja repetir um bloco, ou quando precisa iterar sobre uma sequência (como listas, strings ou dicionários).
2. **`while`**: Utilizado quando você quer que a repetição continue *enquanto* uma condição específica for verdadeira, sem saber exatamente quantas vezes o loop rodará.
3. **Controle de Fluxo (`break`, `continue`)**:
   - `break`: Interrompe completamente o loop antes que ele termine naturalmente.
   - `continue`: Pula a iteração atual e vai direto para a próxima rodada do loop.

Dominar os laços é essencial para processar grandes quantidades de dados e manter seu código limpo (DRY - Don't Repeat Yourself).
