# Condições (Estruturas de Decisão)

Nesta pasta, estão agrupados exercícios que testam a lógica de decisão do seu código.

## Tópicos Abordados:

1. **`if`, `elif` e `else`**: Estruturas clássicas para fazer o código tomar caminhos diferentes dependendo de uma condição booleana (Verdadeiro ou Falso).

A lógica condicional é o que dá "inteligência" ao seu programa, permitindo que ele reaja a diferentes cenários!
