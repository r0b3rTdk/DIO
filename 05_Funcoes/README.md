# Funções

Nesta pasta exploraremos a criação de blocos de código reutilizáveis no Python.

## Tópicos Abordados:

1. **Criação de Funções (`def`)**: Como encapsular uma lógica que você usa frequentemente dentro de uma função.
2. **Parâmetros e Argumentos**: Como enviar dados para dentro da sua função para torná-la dinâmica.
3. **Retorno (`return`)**: Como fazer com que a função devolva o resultado processado para ser salvo numa variável ou usado no resto do código.
4. **Escopo**: Entendendo a diferença entre variáveis globais (fora da função) e locais (dentro da função).

Criar funções é o primeiro passo para ter um código bem estruturado, modular e de fácil manutenção.
