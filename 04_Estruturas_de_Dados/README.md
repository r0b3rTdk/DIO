# Estruturas de Dados

Esta pasta concentra exercícios focados nas três principais coleções de dados nativas do Python. Aprender a organizar e armazenar múltiplos dados é um divisor de águas na programação.

## Tópicos Abordados:

1. **Listas (`list`)**:
   - Coleções ordenadas e mutáveis (podem ser alteradas).
   - Ótimas para guardar uma sequência de itens.
   - Métodos principais: `.append()`, `.pop()`, `.sort()`, etc.
2. **Tuplas (`tuple`)**:
   - Semelhantes às listas, porém são **imutáveis** (não podem ser alteradas depois de criadas).
   - Usadas para dados que não devem sofrer modificação durante a execução do programa (como coordenadas, configurações fixas).
3. **Dicionários (`dict`)**:
   - Armazenam dados no formato `chave: valor`.
   - Extremamente rápidos para busca de dados através de chaves únicas.
   - Métodos principais: `.keys()`, `.values()`, `.items()`.
