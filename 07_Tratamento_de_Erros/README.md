# Tratamento de Erros e Exceções

Nesta pasta ficam os arquivos focados em evitar que seu programa quebre (congele ou feche inesperadamente) quando algo dá errado.

## Tópicos Abordados:

1. **`try` e `except`**: Capturar e tratar os erros para exibir uma mensagem amigável ao usuário em vez do código explodir um alerta vermelho.
2. **`else` e `finally` no Try/Except**: Executar blocos de código garantidamente (como fechar conexões de banco de dados), independente de ter dado erro ou não.
3. **Levantar Exceções (`raise`)**: Como forçar um erro quando uma regra de negócio sua é quebrada.
