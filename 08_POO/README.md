# Programação Orientada a Objetos (POO)

Aqui entra o paradigma de Orientação a Objetos, a forma como a maior parte dos grandes sistemas no mundo é estruturada.

## Tópicos Abordados:

1. **Classes e Objetos**: Como criar as plantas (Classes) que dão origem aos elementos reais na memória (Objetos).
2. **Atributos e Métodos**: Atributos são as características do objeto (ex: cor, modelo) e Métodos são o que ele consegue fazer (ex: acelerar, frear).
3. **Método Construtor (`__init__`)**: Como construir o seu objeto recebendo parâmetros diretamente na criação.
4. **Pilares da POO**:
   - Herança
   - Polimorfismo
   - Encapsulamento
